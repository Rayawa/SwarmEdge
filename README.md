# SwarmEdge

English | [简体中文](README_zh.md)

Research notes on device-edge-cloud collaboration, peer communication and on-device NPU inference.

## Overview

The project is at the problem-definition stage. It explores how edge/cloud coordination, direct node communication and local inference could support a concrete task. The repository contains research material and archived proposals, with no deployable cluster implementation.

## Technology and Dependencies

No runtime dependencies are currently required. OpenHarmony, Ascend/CANN and potentially openEuler are candidate technologies; hardware, versions, algorithms and evaluation criteria are not yet fixed.

## Repository Structure

- `README.md` — current scope and status
- `archive/` — historical proposals and references

## Quick Start

```bash
git clone https://github.com/Rayawa/SwarmEdge.git
cd SwarmEdge
```

Read this overview first, then consult the [archived proposal notes](archive/2026-10-20_早期方案_未采纳/归档说明.md) as needed. Archived assumptions and budgets are not current commitments. There is no application to install or launch.
