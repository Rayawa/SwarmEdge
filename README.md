# SwarmEdge

Exploring device-edge-cloud collaboration, peer-to-peer cluster communication, and on-device NPU inference.

SwarmEdge 是一个处于问题定义与方向探索阶段的研究项目，关注端边云协同、集群节点通信与端侧 NPU 推理的组合应用。

**当前状态：方向探索。** 仓库目前保存研究说明和历史草案，尚无已实现、可部署的集群系统。应用场景与具体研究问题仍待确定。

## 核心探索方向

| 方向 | 探索内容 |
| --- | --- |
| 端边云一体化 | 将端、边、云作为整体考虑，研究各层如何分工和协同完成具体任务。 |
| 集群节点间通信 | 在主机与节点通信之外，探索节点之间直接交换信息与协同的机制。 |
| 节点侧 NPU 推理 | 探索在集群端侧节点执行本地推理，以及它与整体任务协同的关系。 |

以上为拟探索方向，具体贡献需要随问题定义和实验验证逐步明确。

## 技术底座意向

- **设备侧**：OpenHarmony。
- **端侧推理**：昇腾 NPU 与 CANN。
- **主机侧**：可采用 openEuler。

这些是技术意向，板卡选型、系统版本以及 OpenHarmony 与 CANN 的组合适配情况尚待核实。

## 当前需要回答的问题

1. 哪个具体任务需要同时具备端边云协同、节点间通信和端侧推理？
2. 各层职责、节点形态与通信机制如何围绕该任务确定？
3. 相比现有方案，组合设计能带来什么可验证的价值？
4. 应采用哪些基线、数据和实验指标来验证效果？

应用场景、节点数量、模型、算法、预算及验收指标尚未确定。
