# SwarmEdge

[English](README.md) | 简体中文

关于端边云协同、节点间通信与端侧 NPU 推理的研究笔记。

## 项目概述

项目处于问题定义阶段，探索端边云分工、节点直接通信和本地推理如何服务具体任务。当前保存研究资料与历史草案，没有可部署的集群实现。

## 技术栈与依赖

当前无需运行时依赖。OpenHarmony、Ascend/CANN 及可能采用的 openEuler 属于候选技术，硬件、版本、算法与评估标准尚未确定。

## 文件结构

- `README.md` — 当前范围与状态
- `archive/` — 历史方案与资料

```bash
git clone https://github.com/Rayawa/SwarmEdge.git
```
