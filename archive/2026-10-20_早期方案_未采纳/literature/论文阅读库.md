# 论文阅读库

检索截至2026-10-20。共19篇。阅读层级逐条标注；未标为全文精读的条目不作全文复现依据。年份区分首发、修订和会议发表。未核实的录用状态不推定。

优先顺序：P17 → P19 → P18（2026 近邻，差异表见 research/10）→ P14 → P01 → P07 → P06 → P09 → P10 → P16；其余按研究路线选读。

- 原文：[原始页面](https://arxiv.org/abs/2205.09778)
- 阅读层级：正文§IV-E、§V；表I
- 可借鉴：云/边卸载与图像压缩已是成熟研究方向。可复用节点拆分与压缩实验思路。
- 不可直接外推：其表I是在特定10 Mbps链路的往返实验；不能把论文加速比当成本项目指标。

## P19 · Efficient Vision-Language-Action Management and Serving for Robot Factories

- 作者：Dionysios Adamopoulos；Nattapol Chanpaisit；Basel Fakhri；Christina Giannoula
- 年份/版本：2026；arXiv v1，2026-09-10；预印本
- 原文：[原始页面](https://arxiv.org/abs/2609.12075)
- 阅读层级：正文§4—§5；实验、消融与放置策略
- 可借鉴：集中式多机器人 VLA 服务：VLM+ADiT 两级在同 GPU 双流执行，EDF 排队与按 GPU 负载上限的整数规划放置；4 GPU、8 模型、64 机器人达 98% SLO。
- 不可直接外推：只建模网络时延，不建模上行带宽；只调度已到达的请求，不决定谁该发；任务是操作而非搜索。
